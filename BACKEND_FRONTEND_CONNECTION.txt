ASTROHEALTH — FRONTEND / BACKEND CONNECTION
===========================================

PROJECT STRUCTURE
- backend/                  Flask API and SQLite database
- frontend/static/          Existing plain HTML/CSS/JavaScript app

RUN THE BACKEND
1. Open a terminal at the project root (the folder containing backend/ and frontend/).
2. Install dependencies:
      python -m pip install flask flask-cors requests
3. Start the Flask server:
      python -m backend.app

The backend listens at:
      http://127.0.0.1:5001

IMPORTANT: Run from the project root with `python -m backend.app`.
The Python files import each other using the `backend.` package path.

RUN THE FRONTEND
1. Keep the Flask backend terminal running.
2. In VS Code, open frontend/static/index.html with Live Server.
3. Open the Live Server URL, normally:
      http://127.0.0.1:5500/frontend/static/index.html
   (The exact path depends on which folder Live Server is serving.)

The existing frontend API base is:
      http://127.0.0.1:5001
Flask-CORS is already enabled in backend/app.py.

WHAT NOW COMES FROM THE BACKEND
- Crew list: GET /api/crew
- Latest astronaut readings: GET /api/vitals/latest
- Health evaluation: GET /api/status
- Open alerts: GET /api/alerts
- Historical readings: GET /api/vitals/history
- Personal baseline: GET /api/baseline
- Indicator guidance: GET /api/guidance/<indicator>
- NASA radiation: GET /api/radiation/latest
- NASA radiation history: GET /api/radiation/history
- NASA radiation anomaly comparison: GET /api/radiation/anomaly

DATA PROVENANCE — PLEASE READ
- Heart rate, SpO2, temperature, blood pressure, glucose, sleep, mood and stress are generated by the project's existing Python simulator and stored in SQLite. They are NOT live wearable sensor feeds.
- Radiation values are fetched by the backend from NASA OSDR RadLab and stored in SQLite. The current query in backend/radiation.py is a historical ISS DosTel sample window (April 1–2, 2022), not live radiation telemetry and not an individual astronaut dose.
- NASA RadLab units: absorbed dose rate is μGy/hour; dose equivalent rate is μSv/hour; flux is cm^-2 sr^-1 s^-1.
- The backend attempts the configured NASA RadLab fetch in a background thread at startup. If the NASA service is unavailable, the dashboard will show that NASA records are unavailable rather than substituting fabricated radiation values.
- The radiation anomaly badge compares the selected instrument's value with its stored historical readings. It is a statistical flag, not a medical or radiation-safety assessment.
- The frontend's existing mock fallback remains in place for API failures. The header's MOCK DATA ACTIVE indicator means one or more frontend API requests fell back to mock data.
